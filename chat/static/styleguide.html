How this page works

This page loads the app's real stylesheets (tokens.css, base.css, chat.css, orb.css) and draws most components with the app's own code (stream.js: the drop, the trail, sources, quote checks, citation numbers). Change a component in the CSS and it changes here and in the app at the same time; nothing is copied, so nothing goes stale. Switch the theme at the top right to see every component in Light, Dark and Blossom.

Open it at /static/styleguide.html. Each section names its class names and the file they live in. The guide's own layout uses sg- classes (styleguide/guide.css); everything else is the app.

Colour tokens

tokens.css: one block per theme on html[data-theme]. Components only use these variables, so a theme is just a new block. The values below are read live from the page.
