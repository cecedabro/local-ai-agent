# Project templates

Copy into a new project repo, fill in `REPLACE_ME`, write your tests under
`tests/` (and `contract/` if shared), then run `agent-loop` from the devbox.

You write: `SPEC.md`, `AGENTS.md`, `PLAN.md`, tests, a `Makefile` with a `check` target.
The agent writes: everything else, plus `PROGRESS.md`.
