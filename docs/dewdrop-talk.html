Dewdrop, from hardware to prompt

How a gaming PC, a small Kubernetes homelab and a local language model become a chat app for family and friends, with a research mode that only answers from checked sources.

RTX 3080 TiQwen3.6-35B-A3Bllama.cppk3s + FluxFastAPIClear Source
What it is

A chat app that never leaves the house

Private

Every question is answered by a model on our own GPU. No cloud AI, no tracking. Invite-only accounts with passwords and passkeys.

Useful

General chat with web search (our own SearXNG), code with highlighting and download, folders, files in and out, installable on a phone.

Careful

Clear Source answers medical questions only from Dutch guidelines and PubMed, and checks every quote word for word.

Built mostly by a coding agent running on the same GPU, overnight, from small test-judged tasks.

Layer 1 · hardware

Two homes for the work

The gaming PC (sleeps)

  • RTX 3080 Ti, 12 GB video memory
  • 32 GB DDR4 system memory
  • Windows 10 + WSL2 Ubuntu
  • Only job: serve the model
  • Sleeps between jobs, woken over the network

The homelab (always on)

  • Small k3s cluster, GitOps with Flux
  • Secrets in OpenBao
  • Runs Dewdrop, the status service, the agent's devbox, SearXNG, the waker
  • Public door: Cloudflare Tunnel
  • Private door: Tailscale
Layer 2 · the model

A 35B model that behaves like a 3B one

Model
35B

Qwen3.6-35B-A3B, a mixture of experts: per token a router picks a few experts, so only ~3B parameters do work.

Size on disk
4-bit

UD-Q4_K_XL GGUF, ~23 GB. Too big for 12 GB, so the experts of 26 layers live in RAM (--n-cpu-moe 26); the rest on the GPU.

Speed-up
MTP

The model drafts 2 tokens ahead and checks them in one pass; ~79 % are accepted.

Clients never see the real name: it is served as coder, so it can be swapped without touching anything else.

Layer 4 · power

Asleep until someone needs it

1
Work arrivesA chat message or an agent job needs the model; the PC is asleep (S3).
2
Wake-on-LANA small pod on the host network sends the magic packet; Windows wakes, WSL starts llama-server (~2 min to load).
3
Keep awakeWhile an agent runs it refreshes a /run/ai/busy flag over SSH; a Windows task keeps the PC up while the flag is fresh.
4
Back to sleepNo flag, no activity: Windows sleeps again. ai pause on the Mac frees the GPU for gaming.

Layer 6 · the gateway

One GPU, many askers

Lanes

Every client has a key and a lane. Interactive (Dewdrop, the quick chat) goes before batch (the agents). Prompts are never stored; timings and token counts are.

chat→queue→llama-server

The catch

llama-server handles one request at a time. A chat request can skip the queue, but it can't interrupt a request that is already running. While the agent works, every chat call waits for the agent's current one: a Clear Source answer (~10 calls) can take minutes.

Layer 7 · the app

Dewdrop on the server

Stack

Python 3.11, FastAPI, Jinja2 pages, httpx to the gateway, SQLite with one owner check per query. No frontend framework, no build step.

Modules

answer (one answer), gateway (streaming, tool calls), context (window, summaries), profiles, tools, research, verify, files.

Safety

argon2 + passkeys, rate-limited login, HttpOnly cookies, CSRF header on every write, strict CSP, escaped Markdown, SSRF-safe page fetching.

Clear Source · the research profile

Strict by construction, not by asking nicely

1
UnderstandOne call plans searches: PubMed in English with MeSH headings, Dutch guideline sites in Dutch.
2
SearchThe app searches: MeSH checked, filters, broader on too few hits, long pages focused on the relevant part.
3
Read one by one"Copy passages that help." Kept only if they appear word for word. Too little? A second round with other words.
4
Write and checkThe answer is written only from the passages; every quote gets ✓ or ⚠.

Default sources

Richtlijnendatabase · Farmacotherapeutisch Kompas · Kinderformularium · RIVM · Lareb · Geneesmiddelenbulletin · Thuisarts · PubMed

Nothing found? The app answers "no reliable evidence" itself; the model never fills the gap from memory.

The checker

Every quote compared with its source

How

  • Normalise: case, quotes, dashes, spaces
  • A quote must appear in the source it cites → ✓, else ⚠
  • A claim of 8+ words without [n] → listed as uncited
  • The short answer, lead-ins ending in ":" and "the sources don't say…" are not claims

Example (real model)

Is ibuprofen safe during pregnancy?

"Tijdens de eerste helft van de zwangerschap alleen op strikte indicatie toepassen… Gebruik is gecontra-indiceerd tijdens het 3e trimester." [1] ✓

[1] Farmacotherapeutisch Kompas, ibuprofen (systemisch), found 23 000 characters down the page.

Lessons from testing with the real model

Tests pass; the real world still surprises

PubMed said "429"

Too many requests per second. Fix: one throttled path for every NCBI call, retries, optional API key.

The model wrote searches as text

The second round silently did nothing. Fix: accept both forms, show the format in the prompt.

Pages were cut at 8 000 characters

The Kompas pregnancy section starts at 23 000. Fix: read the whole page, keep the paragraphs that match (rare words weigh more).

One GPU, one request

Chat waits behind the agent; and after a sleep the PC once ran at half speed. Measure, then restart the server, not the PC.
